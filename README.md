# Ayo Build

Collaborative build. Scope and stack TBD — this repo is the starting point.

## Getting started

```bash
git clone https://github.com/ghayzal/ayo-build.git
cd ayo-build
```

## Working together

- Branch off `main` for anything non-trivial: `git checkout -b your-name/what-youre-doing`
- Open a pull request instead of pushing straight to `main`
- Keep commits small enough that someone else can read them
